# Combined skills are built by copying unit content, and the output is committed

Each area's combined skill is generated by a build script that copies the content of its units in, with a source-path marker before each block. The generated files are committed, and a freshness check fails if they differ from the build output. We chose this over having one large hand-written skill per area, so that each topic is tested on its own and has one source of truth. The cost is that a generated file must never be edited by hand.
